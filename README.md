# 🏏 IPL Match Data Analysis using Python

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Indian Premier League (IPL) dataset using Python. The objective is to analyze match and player performance, identify trends, and generate meaningful insights through data visualization.

The project demonstrates skills in **data cleaning, preprocessing, visualization, and insight generation**, making it suitable for Data Analyst and Data Science portfolios.

---

## 🎯 Objectives

* Perform data cleaning and preprocessing.
* Analyze team and player performance.
* Study season-wise IPL trends.
* Visualize key statistics using charts.
* Generate actionable insights from historical IPL data.

---

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📂 Dataset

This project uses the publicly available **IPL Dataset** containing:

* **matches.csv** – Match-level information
* **deliveries.csv** – Ball-by-ball information

Dataset Source:
https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020

## 📊 Analysis Performed

### ✔ Player Analysis

* Season-wise winning teams

* Count Plots
